SLIDE 2: PROBLEM UNDERSTANDING (THE NER LANDSLIDE CRISIS)
----------------------------------------------------------------------------------------
• Core Ground Reality:
  - North Eastern Region accounts for over 70% of non-Himalayan landslide fatalities in India.
  - Fragile Disang shale formations, young tectonic slopes, and world-record precipitation (Sohra/Mawsynram)
    trigger rapid debris flows.
  - Lifeline highway corridors (NH-44 in Meghalaya, NH-29 in Nagaland) and railway links (Haflong)
    are repeatedly severed for weeks every monsoon.
• Real Statistic:
  - Over 4.5 crore citizens affected across 8 NER states.
  - In 2024 alone, over 180 fatal slope failures and Rs 1,400+ Cr in highway infrastructure damage.
• Gaps in Current Solutions:
  - Static PDF susceptibility maps by GSI with zero real-time rainfall response.
  - Citizens have no tool to check "Is my current GPS position safe right now?".
  - Emergency notification (NDRF, highway barriers, hospitals) relies on slow, fragmented phone calls.

----------------------------------------------------------------------------------------
SLIDE 3: PROPOSED SOLUTION (NER-LEWS)
----------------------------------------------------------------------------------------
• One-Line Pitch:
  "An AI-powered, multimodal early warning GIS platform fusing real-time rainfall telemetry,
   geotechnical hazard models, and automated multi-channel emergency dispatch for the NER."
• Three Core Pillars:
  1. Dynamic Geotechnical AI: Fuses live Open-Meteo precipitation, pore-water pressure, and slope angles
     into an XGBoost + Random Forest ensemble (LandslideNet v3.2) yielding live 0-100% risk scores.
  2. 1-Click Citizen GPS Safety Analyzer: Instant browser geolocation check providing clear visual status
     ("YOU ARE SAFE" vs "CRITICAL RISK") with live rain, temp, and evacuation guidance.
  3. Automated 1-Click Emergency Response: Unified dispatch triggering NDRF 1st Bn mobilization,
     NH-44 highway closures, medical alerts, and mobile push sirens without API bottlenecks.

----------------------------------------------------------------------------------------
SLIDE 4: TECHNICAL ARCHITECTURE & STACK
----------------------------------------------------------------------------------------
• Data Flow (4-Tier Pipeline):
  1. Ingestion: Open-Meteo REST API (hourly rain gauges) + in-situ sensors + GSI NLSM shapefiles.
  2. Inference: LandslideNet v3.2 (XGBoost + SHAP feature attribution weights).
  3. Spatial GIS: React-Leaflet hardware-accelerated vectors with ESRI World Topo & Satellite layers.
  4. Dispatch: Zero-config ntfy.sh webhooks, automated priority SMS & NDRF webhooks.
• Tech Stack:
  - Frontend: React 18, Vite 5, React-Leaflet 4, Axios, Tailwind CSS.
  - Backend: Python 3.10+, FastAPI (Async/Await), Uvicorn ASGI, SQLAlchemy ORM, Pydantic v2.
  - Maps: ESRI World Topo Map + ESRI High-Res World Imagery + ESRI Boundaries & Places overlay.
  - ML: Scikit-Learn, XGBoost, SHAP, Joblib.

----------------------------------------------------------------------------------------
SLIDE 5: INNOVATION & NOVELTY
----------------------------------------------------------------------------------------
• 1. Sovereign-Constrained Vector GIS: All 16 regional polygons are strictly mathematically anchored
     inside India's sovereign borders with zero spillover into Tibet, Bangladesh, or Myanmar.
• 2. Non-Linear Meteorological Stress-Testing: Interactive 0.5x to 2.5x rainfall slider using
     geotechnical damping curves to simulate cloudburst scenarios dynamically for disaster commanders.
• 3. Dual-Layer Hybrid Satellite Stack: High-res satellite imagery seamlessly stacked with administrative
     labels so hamlets and mountain roads remain clear during disaster coordination.
• 4. Zero-Bottleneck Siren Dispatch: Autonomous push notification webhooks delivering siren warnings
     to responder units in under 2.3 seconds with zero third-party API dependencies.
